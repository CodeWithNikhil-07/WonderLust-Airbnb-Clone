# WonderLust - Airbnb Clone

A full-stack Airbnb-inspired web application built using MERN technologies.

## Features

- View all listings
- View listing details
- Create new listings
- Edit and update listings
- MongoDB database integration
- Dynamic routing with Express

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML/CSS

## Future Features

- Delete listings
- Authentication
- Image upload with Cloudinary
- Reviews and ratings
